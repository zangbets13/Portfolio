Game flow, charted like a market

Pulls each team's live scoring line straight from ESPN's own game-flow data — no manual inputs, no odds, nothing synthetic. Each team's cumulative score is its own line. The gap between them is the spread. The trailing slope of each line is its scoring rate. A divergence is flagged when the trailing team is scoring faster than the leader while the board margin is still widening — then the tool checks whether that actually preceded a lead change, so the pattern gets tested against real outcomes instead of just eyeballed.
